# Doge Agency

A creative studio website built with React, TypeScript, and SCSS, focused on visual design, responsive layouts, and interactive frontend experiences.

The project explores how a content-heavy studio website can combine animation, media, navigation, and responsive layouts without making the interface difficult to use.

## Live Demo

https://doge-challenge.vercel.app/

## Features

* Responsive studio landing page
* Animated hero section with parallax effects
* Case study carousel
* Video/showreel section
* Image gallery with lightbox
* Services and capabilities sections
* About page
* Contact section
* Responsive navigation
* Mobile and desktop layouts
* Interactive UI elements and transitions

## Tech Stack

* React
* TypeScript
* React Router
* SCSS
* Lucide React
* Vite/Webpack tooling

## Frontend Details

### Responsive layouts

The layouts are designed for different viewport sizes rather than relying on a single desktop composition. Content, typography, navigation, galleries, and interactive sections adapt across mobile, tablet, and desktop.

### Animation

Motion is used selectively for page transitions, hover states, scrolling sections, and the hero experience. The goal is to add movement without making the interface difficult to navigate.

### Media handling

The project includes video and image-heavy sections, with dedicated layouts for galleries, case studies, and the showreel experience.

### Component structure

The interface is split into reusable components and page sections so that individual parts of the experience can be developed and maintained independently.

## Running Locally

```bash
git clone https://github.com/frdooo/doge_challenge.git
cd doge_challenge
npm install
npm run dev
```

Then open the local development server shown in the terminal.
